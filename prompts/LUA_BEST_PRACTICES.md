# СТАНДАРТЫ И ОГРАНИЧЕНИЯ LUA (MWS Octapi LowCode)

Вы пишете код для специализированной LowCode-платформы.

## 1. Доступ к переменным и возврат результата

- Для навигации по структурам и доступа к данным используйте строго прямую цепочку ключей таблиц Lua. Пример: `wf.vars.json.IDOC.ZCDF_HEAD`.
- Все переменные платформы хранятся в `wf.vars`. Исходные переменные в `wf.initVariables`.
- Каждый скрипт должен завершаться оператором `return` для возврата итогового результата (например, `return result`).
- Скрипты выполняются изолированно. Избегайте сохранения промежуточных результатов в `wf.vars`.

## 2. Типы данных, массивы и строки

- Создание пустого массива: `local result = _utils.array.new()`.
- Проверка на число: используйте `type(value) == "number"`.
- Работа со строками: Для поиска подстрок и регулярных выражений используйте только функцию `string.match`.
  - Правильно: `local domain = string.match(email, "@(.+)")`
  - Ошибочно: `email("@(.+)")` (строка не является функцией).

## 3. Синтаксис и конструкции

- Используется Lua 5.5.
- Разрешены только базовые конструкции: `if..then..else`, `while..do..end`, `for..do..end`, `repeat..until`.
- Если в ТЗ не указаны конкретные имена полей для сортировки или фильтрации, используйте базовые (например, `value`) или возвращайте `nil`. Выдумывать имена свойств объектов запрещено.
