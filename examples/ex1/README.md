# Демонстрация 1: Работа `/generate` и Агента-Аналитика

В этой демонстрации мы покажем формальное соответствие требованиям хакатона (наличие эндпоинта `/generate` и заданный JSON-формат), а также то, как система защищает пользователя от "слепой" генерации кода при недостатке данных.

> **Требования для запуска демо:** У вас должны быть установлены утилита `jq` и компилятор `lua5.5`. Эмулятор среды находится в корне проекта: `test_runner.lua`.

### Шаг 1. Формальный запрос

Сделаем простой запрос, чтобы убедиться, что API возвращает ожидаемый схемой JSON (`{"result": "lua{...}lua"}`).

```bash
curl -X POST http://localhost:8000/generate \
-H "Content-Type: application/json" \
-d '{"prompt": "Найди максимальное число в массиве wf.vars.numbers"}'
```

_Вы увидите сырой JSON ответ с кодом внутри._

### Шаг 2. Проверка работы Агента-Аналитика

Зададим **неоднозначную** задачу. Попросим отфильтровать массив, но не скажем как.
Сразу передадим результат в наш эмулятор `test_runner.lua`, чтобы посмотреть на сгенерированный код.

```bash
curl -s -X POST http://localhost:8000/generate \
-H "Content-Type: application/json" \
-d '{"prompt": "Отфильтруй массив чисел wf.vars.numbers"}' \
| jq -r '.result' | sed 's/^lua{//; s/}lua$//' | tee script.lua && cat script.lua | lua5.5 ./test_runner.lua
```

**Результат:** Код не упадет, но Агент-Аналитик добавит в начало скрипта комментарий: `-- Условия фильтрации:`

### Шаг 3. Имитация Human-in-the-Loop

Мы получили обратную связь от модели. Уточняем наш промпт и запускаем заново.

```bash
curl -s -X POST http://localhost:8000/generate \
-H "Content-Type: application/json" \
-d '{"prompt": "Отфильтруй массив чисел wf.vars.numbers: оставь только числа больше 10. Строки и nil игнорируй."}' \
| jq -r '.result' | sed 's/^lua{//; s/}lua$//' | tee script.lua && cat script.lua | lua5.5 ./test_runner.lua
```

Ожидаемый результат:

```
[+] РЕЗУЛЬТАТ ВЫПОЛНЕНИЯ:
[1]     15
[2]     42
[3]     100
```
