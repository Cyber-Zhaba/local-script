# 🚀 LocalScript: Локальная мультиагентная система для генерации Lua-кода

**LocalScript** — это AI-решение для LowCode-платформы (MWS Octapi), работающее **полностью в закрытом контуре**. Оно переводит задачи с естественного языка в готовый к использованию Lua-скрипт, опираясь на корпоративную базу знаний и строгие правила синтаксиса.

## ⚡ Quick Start (Быстрый запуск)

### Требования

- Docker & Docker Compose
- NVIDIA GPU (мин. 8 GB VRAM) + NVIDIA Container Toolkit

### Запуск

1. Клонируйте репозиторий.
2. Убедитесь, что в файле `.env` указана нужная модель:

   ```env
   LLM_MODEL=qwen2.5-coder:7b-instruct
   ```

3. Поднимите контейнеры:

   ```bash
   docker compose up --build
   ```

4. **⏳ ВАЖНО:** При первом запуске сервис `init` скачает модель в Ollama. Бэкенд API будет доступен **только после того**, как в консоли появится ASCII-арт `Local Script`.

## 🎯 Бизнес-ценность

- **Zero Data Leakage:** Никаких внешних API (OpenAI, Anthropic). Код и данные не покидают инфраструктуру компании.
- **Работа на 8 GB VRAM:** Благодаря разделению процессов (LLM на GPU, эмбеддинги на CPU) система работает на бюджетном железе без offload'а в оперативную память.
- **Предсказуемость:** LLM не "галлюцинирует" синтаксис. Каждый скрипт проходит _детерминированную проверку_ локальным компилятором `luac` перед выдачей пользователю.
- **Human-in-the-Loop:** Если задача поставлена неоднозначно, система задает уточняющие вопросы, а не пишет код наугад.

## 🧠 Архитектура

Система построена на базе 4 "агентов", управляемых чистым Python-бэкендом (FastAPI) без тяжеловесных фреймворков:

1. **Аналитик:** Проверяет запрос на полноту данных и формирует ТЗ.
2. **RAG-модуль:** Ищет релевантные примеры в локальной БД Qdrant (эмбеддинги считаются на CPU через FastEmbed).
3. **Кодер (Qwen2.5-Coder:7b):** Пишет код строго по `LUA_BEST_PRACTICES`.
4. **Фиксер + Чекер:** Python проверяет синтаксис компилятором. При ошибке Фиксер чинит баг в цикле.

## ⚙️ Конфигурация базы знаний (Prompts & RAG)

Вся логика и правила агентов вынесены в директорию `prompts/`. Вы можете менять поведение системы "на лету" без переписывания кода:

- `prompts/agents.json` — Системные промпты для Аналитика, Кодера и Фиксера.
- `prompts/LUA_BEST_PRACTICES.md` — Жесткие правила написания кода (запреты, работа с переменными `wf.vars`).
- `prompts/examples.json` — База данных для RAG (Few-Shot примеры). При рестарте автоматически векторизуется и загружается в Qdrant.
